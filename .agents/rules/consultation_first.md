# Rule: Mandatory Discussion & Approval Before Code Changes

## Core Constraint:
1. **Never make code or database changes without prior discussion and explicit user approval.**
2. When investigating a bug or answering a question:
   - Only view files and run non-modifying diagnostics.
   - Present the explanation and proposed solution to the user.
   - Wait for the user to review, agree, or adjust the plan before applying any file edits or commands.
