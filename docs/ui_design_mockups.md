# Zorva — Master UI Design System & High-Fidelity Mockups

Welcome to the **Zorva** Master UI Design Suite. Every screen in the Zorva application has been crafted with a cohesive, ultra-modern luxury glassmorphism design system.

---

## 🎨 Core Design System Tokens

* **Primary Background**: Deep Onyx (`#08080A`)
* **Card Surfaces**: Dark Metallic Glass (`#121216` ➔ `#1A1813`)
* **Championship Gold Accent**: `#E5C158` (Primary), Metallic Gradient (`#FFF0B3` ➔ `#E5C158` ➔ `#B88E1C`)
* **Accent Colors**: Green `#34D399` (Wins), Red `#F87171` (Losses)
* **Typography**: Google Fonts Inter with high-contrast weight hierarchy & uppercase tracking

## 📱 Core Application Screens

1. **Sports Passport & Home Dashboard**: Ambient gold aura mesh, metallic rating score (`1,567 PTS`), 4 glass stat pills, glowing metallic floating quick log button.
2. **Sub-10s 1-Tap Match Logger**: Opponent selection chips with city & live Glicko rating, 1-tap score preset buttons (`2-0`, `2-1`, `3-0`).
3. **Ranked City Leaderboards & Podiums**: Community vs. Official Zorva rating context filters, metallic podium badges (🥇 Gold, 🥈 Silver, 🥉 Bronze).
4. **5-Tap Interactive Player Profiling**: Step progress bar, 1-tap profiling cards (Hand, Style, Grip, Rubber), calibrated starting baseline (1,000 PTS, 1,200 PTS, 1,500 PTS, Custom Known Rating).
